# Стадия 2d — адаптивное обучение с albumentations

Описание новых настроек обучения и инференса, добавленных для повышения
устойчивости детекции дронов в сложных условиях съёмки (засветки, низкое
качество картинки, туман, шум, размытие движения).

## 1. Обоснование

Анализ видео `555.MP4` (1824 кадра, 1280×720, 30 FPS) выявил проблемы:

| Проблема | Данные |
|----------|--------|
| Низкий conf модели | 0.30–0.35 (модель неуверена) |
| Засветка кадров | max яркость 242–255 почти во всех кадрах |
| Ложные срабатывания | 4 случая + bbox на весь кадр (465K px) |
| Мелкий дрон | area 3K–27K px (0.2–2% кадра) |
| Низкий % детекции | 10.5% (192/1824 кадров) |

Для решения добавлены: кастомные аугментации (albumentations), усиленные
параметры YOLO, новая стадия обучения 2d и адаптивный инференс с CLAHE.

---

## 2. Кастомные аугментации (albumentations)

Установлен пакет `albumentations==2.0.8`. В стадию 2d добавлены 9 трансформаций,
каждая применяется с заданной вероятностью:

| Трансформация | Параметры | P | Назначение |
|---------------|-----------|---|------------|
| `CLAHE` | clip_limit=4.0, tile_grid_size=(8,8) | 0.30 | Адаптивная эквализация гистограммы — борьба с засветкой и низким контрастом |
| `RandomSunFlare` | flare_roi=(0,0,1,0.5), src_radius=100 | 0.20 | Имитация бликов и засветов от солнца |
| `RandomFog` | fog_coef_range=(0.1,0.4), alpha_coef=0.08 | 0.15 | Дымка/туман — снижение контраста как в реальных условиях |
| `GaussNoise` | std_range=(0.05,0.2), mean_range=(0.0,0.0) | 0.20 | Шум низкого качества картинки |
| `ISONoise` | color_shift=(0.01,0.05), intensity=(0.1,0.5) | 0.15 | Цветовой шум матрицы (высокий ISO) |
| `MotionBlur` | blur_limit=(3,11) | 0.20 | Размытие движения (дрон в движении, дрожание камеры) |
| `ImageCompression` | quality_range=(40,85) | 0.20 | Артефакты JPEG-сжатия (низкое качество видео) |
| `RandomBrightnessContrast` | brightness_limit=0.3, contrast_limit=0.3 | 0.25 | Случайные изменения яркости и контраста |
| `RandomGamma` | gamma_limit=(70,130) | 0.20 | Гамма-коррекция (разная экспозиция) |

### Интеграция в Ultralytics

Albumentations интегрируются через monkey-patching класса
`ultralytics.data.augment.Albumentations.__init__` — дефолтные трансформации
Ultralytics заменяются на кастомный список при старте стадии 2d.

Функция `_patch_albumentations()` в `train/run_yolo26_curriculum.py` подменяет
`__init__`, передавая кастомный список трансформаций вместо `None`.

## 3. Усиленные параметры YOLO (стадия 2d)

| Параметр | Стадия 2c | Стадия 2d | Обоснование |
|----------|-----------|-----------|-------------|
| `hsv_v` | 0.5 | **0.6** | Больше вариаций яркости (засветки/тени) |
| `erasing` | 0.5 | **0.6** | Имитация засветов/препятствий поверх цели |
| `mixup` | 0.25 | **0.3** | Смешивание кадров для устойчивости к фону |
| `lr0` | 0.001 | **0.0005** | Меньший LR — тонкая дообучение без разрушения весов |
| `epochs` | 20 | **10** | Достаточно для адаптации (модель уже обучена на 2a–2c) |

Остальные параметры наследуют стадию 2c:
`scale=0.7, shear=10.0, degrees=25.0, translate=0.3, perspective=0.001,
hsv_h=0.02, hsv_s=0.8, fliplr=0.5, mosaic=1.0, close_mosaic=5, patience=15`.

## 4. Стадия 2d в curriculum-обучении

Стадия 2d — четвёртая и финальная стадия этапа 2 (merged_v1):

```
Этап 1: drone_v2 (крупные дроны)
  └─ 2a: базовая аугментация (scale/hsv/fliplr/mosaic)     [ЗАВЕРШЕНА]
  └─ 2b: +поворот, перспектива, mixup                      [ЗАВЕРШЕНА]
  └─ 2c: +засветка, стирание, сильный blur                 [ЗАВЕРШЕНА]
  └─ 2d: +albumentations (CLAHE, Fog, Noise, SunFlare...)  [В ПРОЦЕССЕ]
```

- **Стартовые веса**: `train/runs/merged_v1_26L_2c/weights/best.pt`
- **Датасет**: `merged_v1` (268K изображений)
- **Выход**: `train/runs/merged_v1_26L_2d/weights/best.pt`
- **Маркер завершения**: `weights/stage_done.msg`

### Запуск

```bash
cd /home/alex/AntiUAV-Detector
venv/bin/python train/run_yolo26_curriculum.py --start-stage 4 --skip-confirmation \
  2>&1 | tee train/curriculum_26L.log
```

### Мониторинг

```bash
tail -f train/curriculum_26L.log
```

### Resume при перезапуске

Скрипт автоматически определяет наличие `last.pt` и продолжает с прерванной
эпохи. Завершённые стадии (с маркером `stage_done.msg`) пропускаются.

## 5. Адаптивный инференс (`adaptive_detect.py`)

Скрипт `train/adaptive_detect.py` — инференс с preprocessing и трекингом
для сложных условий съёмки.

### Возможности

| Компонент | Описание |
|-----------|----------|
| **CLAHE** | Адаптивная эквализация гистограммы (LAB→L-канал). Применяется при засветке (max>240), низкой яркости (<80) или низком контрасте (std<30) |
| **ByteTrack** | Трекинг с `persist=True` — удержание track_id между кадрами даже при пропусках детекции |
| **conf=0.25** | Пониженный порог уверенности для сложных условий |
| **OSD-фильтр** | Отсек ложных срабатываний в краях кадра (HUD/телеметрия) |
| **Фильтр по размеру** | Минимальная площадь bbox = 400 px (отсек шумов) |

### Использование

```bash
# На конкретном видео
venv/bin/python train/adaptive_detect.py video-FPV/Video/555.MP4

# С другой моделью
venv/bin/python train/adaptive_detect.py video-FPV/Video/555.MP4 \
  train/runs/merged_v1_26L_2d/weights/best.pt
```

Результат сохраняется в `<имя>_adaptive.mp4`.

### Результат на 555.MP4 (до обучения 2d)

| Подход | Детекций | % |
|--------|----------|---|
| Обычный (test_videos.py) | 192 | 10.5% |
| Adaptive (CLAHE + трекинг) | 243 | 13.3% |

CLAHE применён на 98.9% кадров — видео сильно засвечено.
Ожидается существенное улучшение после обучения стадии 2d.
