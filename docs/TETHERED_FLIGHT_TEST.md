# Лётные тесты на привязи (этап 3) — структура аппаратной и программной части

## 1. Аппаратная часть

### 1.1 Бортовая (дрон-перехватчик)
| Компонент | Требование / параметр | Статус |
|---|---|---|
| Полётный контроллер | CUAV X7+ Pro (FMU), прошивка ArduPilot ≥ 4.3 | ✅ есть |
| Рама + моторы + ESC | 4-6 шт., согласованы по тяге (≥ 2× вес с БЧ) | ✅ есть |
| Пропеллеры | Балансировка, запасные 2 комплекта | проверка |
| Батарея | LiPo 6S/12S (по конфигу), ≥ 2 шт. + зарядное устройство | проверка |
| GPS/Компас | Ublox M8/M9 + внешний магнитометр (в GPS-модуле), фикс 3D | проверка |
| Сервопривод БЧ | Канал 6 (DO_SET_SERVO PWM=2000 = подрыв) | ✅ есть |
| Приёмник RC | S.Bus/PPM (FrSky/ELRS) — аварийное управление | проверка |
| Питание контроллера | PMU (CUAV PMU V3), BEC | проверка |
| Защита пропеллеров | Ограждения/сетка (обязательно на привязи) | купить/сделать |

### 1.2 Привязь
| Элемент | Требование |
|---|---|
| Трос | Капрон/динамический, длина 10–20 м, разрывная нагрузка ≥ 10× вес дрона |
| Крепление к дрону | Точка крепления по центру тяжести (не к раме сбоку!), карабин |
| Якорь | Груз ≥ 50 кг / анкер в землю, кольцо/вертлюг (защита от скручивания) |
| Страховка троса | Отметка максимальной длины, амортизатор (эластичный участок) |
| Подушка/пеномат | Для дрона при падении на привязи |

### 1.3 Наземная станция
| Элемент | Требование |
|---|---|
| Ноутбук | ROS2 Lyrical, Python 3.14, CUDA-видеокарта (для детектора) |
| USB-кабель | Data, качественный, длиной 1–2 м, разъём под X7+ (USB-C) |
| QGroundControl | Мониторинг, калибровка, параметры (альтернатива MAVProxy) |
| RC-передатчик | Связан с приёмником, режимы: STABILIZE, GUIDED (переключатель), Kill |
| Питание ноутбука | Заряженный, автономность ≥ 2 ч |
| Средства связи | Резервный USB-удлинитель (не radio на этом этапе!) |

### 1.4 Безопасность
- Огнетушитель (порошковый/CO2), аптечка, защитные очки
- Зона: радиус ≥ 30 м свободной площадки, без людей/животных
- Второй человек: один за RC, второй — за ноутбуком/мостом
- Ограничитель тяги: на первой итерации пропеллеры малого шага
- Проверка натяжения троса перед каждым взлётом

## 2. Программная часть

### 2.1 Стек
```
ROS2 Lyrical (установлен)
venv: /home/alex/AntiUAV-Detector/venv (Python 3.14)
Workspace: /home/alex/aerial_nav_ws (копия кода uav_interceptor)
PYTHONPATH: $HOME/AntiUAV-Detector/venv/lib/python3.14/site-packages
```

### 2.2 Компоненты (готово)
| Файл | Назначение |
|---|---|
| `ros2_src/uav_interceptor/mavlink_bridge.py` | Мост MAVLink ↔ ROS2 (исправлен: GUIDED, RTL, geofence, ACK, SET_MESSAGE_INTERVAL, battery из SYS_STATUS) |
| `ros2_src/run_bridge.sh` | Запуск моста: `./run_bridge.sh direct /dev/ttyACM0 115200` |
| `ros2_src/run_cmd.sh` | Команды: telemetry, mode, arm, hover, strike, kill, vel |
| QGroundControl | Калибровка, параметры, мониторинг (вне ROS2) |

### 2.3 Параметры ArduPilot (проверить/выставить через QGC)
| Параметр | Значение | Зачем |
|---|---|---|
| `ARMING_CHECK` | 1 (или без обязательного GPS для теста ARM — опционально) | Проверки перед ARM |
| `FENCE_ENABLE` | 1 | Активация геофенса |
| `FENCE_TYPE` | 1 (радиус) | Круг вокруг home |
| `FENCE_RADIUS` | 30–50 м | Радиус (мост дублирует геофенс haversine) |
| `RTL_ALT` | 1500 (15 м) | Высота RTL |
| `RTL_ALT_FINAL` | 500 | Финишная высота посадки |
| `FS_EKF_ACTION` | 1 (Land) | Отказ EKF → посадка |
| `FS_GPS_ENABLE` | 1 | Потеря GPS → RTL/Land |
| `BATT_LOW_VOLT` / `BATT_CRT_VOLT` | по батарее | Предупреждение/критический разряд |
| `SERVO6_FUNCTION` | 94 (Script) или 51 (RC) — для DO_SET_SERVO | Канал подрыва БЧ |
| `SERIAL0_BAUD` (USB) | 115200 | Скорость USB-линка |

### 2.4 Порядок запуска (на полигоне)
1. **Терминал 1** — мост:
   ```
   cd /home/alex/AntiUAV-Detector
   ./ros2_src/run_bridge.sh direct /dev/ttyACM0 115200
   ```
2. **Терминал 2** — контроль:
   ```
   cd /home/alex/AntiUAV-Detector
   ./ros2_src/run_cmd.sh telemetry      # мониторинг
   ./ros2_src/run_cmd.sh mode           # текущий режим (ждём GUIDED)
   ```
3. **QGroundControl** — параллельно для калибровки/параметров.

### 2.5 Логирование
- `ros2 bag record -a -o ~/logs/tether_$(date +%s)` — запись всех топиков
- Логи ArduPilot на SD (проверить, что SD вставлена)

## 3. Программа испытаний (по шагам)

### 3.0 Предполётная подготовка (земля, без батареи)
- [ ] Калибровка акселерометра, гироскопа, компаса (QGC)
- [ ] Калибровка уровня, проверка направления моторов
- [ ] Проверка RC: режимы, kill-переключатель, фейлсейф RC
- [ ] Привязь закреплена (центр тяжести), якорь на месте
- [ ] Защита пропеллеров установлена

### 3.1 Проверки с батареей (двигатели не вращаются)
- [ ] GPS: фикс 3D, ≥ 10 спутников, HDOP < 1.5
- [ ] EKF: статус 3 (здоров), без ошибок арминга
- [ ] Мост: `link_status OK`, battery (из SYS_STATUS) отображается
- [ ] `run_cmd.sh mode` — режим STABILIZE/FBWB
- [ ] ARM на земле: `run_cmd.sh arm` → ACK ACCEPTED
- [ ] DISARM

### 3.2 Взлёт на привязи (ручной, RC)
- [ ] Взлёт на 1–2 м в STABILIZE (RC), удержание
- [ ] Проверка поведения: дрейф, реакция на газы
- [ ] Посадка, проверка троса и натяжения

### 3.3 GUIDED через мост (ключевой тест этапа 3)
- [ ] В воздухе (2 м): `run_cmd.sh mode` → подтвердить GUIDED
- [ ] `run_cmd.sh hover` — зависание (нулевая скорость)
- [ ] `run_cmd.sh vel 0.5 0 0` — медленное движение вперёд, контроль
- [ ] `run_cmd.sh vel -0.5 0 0` — назад
- [ ] `run_cmd.sh vel 0 0 0.3` — набор высоты
- [ ] RTL: `run_cmd.sh mode` → RTL (или команда RTL из моста) — возврат к home
- [ ] Посадка

### 3.4 Аварийные сценарии
- [ ] **Kill**: `run_cmd.sh kill` на 1 м — мгновенная остановка (падение на подушку)
- [ ] **Потеря связи**: выдернуть USB → failsafe (RTL/Land по настройкам) → восстановить
- [ ] **Геофенс моста**: сымитировать превышение дистанции (в sim) или реально при длине троса > FENCE_RADIUS → RTL
- [ ] **STRIKE (БЧ)**: только после успешных тестов 3.1–3.3, на земле или на 0.5 м, с заглушкой вместо заряда! Проверить DO_SET_SERVO ch6 PWM=2000 в логе

### 3.5 Критерии успеха этапа 3
- [ ] GUIDED в воздухе подтверждён ACK
- [ ] vel-команды отрабатывают без рывков
- [ ] RTL возвращает к home
- [ ] Kill мгновенно останавливает
- [ ] Нет потери heartbeat на протяжении всех тестов
- [ ] Геофенс сработал (RTL) при выходе за радиус

9. Огнетушитель, аптечка, защитные очки

## 5. Риски и меры
| Риск | Мера |
|---|---|
| Разрыв троса → дрон улетает | Трос ×10 прочности, амортизатор, геофенс 30–50 м, RTL |
| Натяжение троса → дрейф | Точка крепления по ЦТ, свободная длина ≥ 2× высоты |
| Потеря USB-связи | Failsafe RC/RTL, дублирующий лог на SD |
| Неожиданный ответ на vel | Малая скорость (0.5 м/с), плавные команды |
| Случайный подрыв БЧ | Заглушка вместо заряда до финальных тестов |
| Перегрев/разряд | Мониторинг battery в телеметрии, BATT_CRT → Land |
